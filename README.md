A full-stack, enterprise-grade e-commerce marketplace and digital catalog for industrial machinery, excavators, heavy construction equipment, and replacement parts. Powered by **React 18, TypeScript, Vite, Tailwind CSS, Supabase**, and an embedded AI knowledge assistant.

## ✨ Key Features

- 🚜 **Heavy Equipment Catalog:** Deep catalog structure supporting heavy machinery (excavators, loaders, rollers, attachments) and TYPHON equipment lines.
- 🤖 **Intelligent Chatbot Knowledge Assistant:** In-app AI customer assistant mapped to structured machine specifications, horsepower, attachments, and alias resolution.
- ⚡ **High Performance & Pre-rendering:** Automated SEO file generation and route pre-rendering scripts for fast page indexing and organic search visibility.
- 🔍 **Dynamic Filtering & Specs Comparison:** Multi-parameter search by tonnage, horsepower, fuel type, and price range.
- 🌐 **Multilingual & Localization Support:** Multi-language catalog dictionaries and compile-time translation scripts.
- 🗄️ **Supabase Integration:** Real-time database management, inquiries storage, and product specification persistence.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Chhunsour/KonstructZ-E-Commerce-Websites.git
cd KonstructZ-E-Commerce-Websites

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📦 Scripts

```bash
npm run dev           # launch local Vite development server
npm run build         # generate SEO files + Vite production build + route pre-rendering
npm run start         # serve production dist build locally on port 3000
npm run seo:generate  # generate dynamic sitemap & robots.txt
npm run seo:check     # validate meta tags and SEO tags completeness
npm run translate     # build and synchronize localization dictionaries
```
